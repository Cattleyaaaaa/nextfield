# V1.1.0 — FIELD SCHOOL 学习区重构

## 新增与改进

- 课程由 12 节扩展为 32 节，全部提供中文与英文内容。
- Agent：12 节，从 Agent 与 LLM 介绍开始，深入提示词、工具、状态、行动循环、RAG、多 Agent 协作、评测与生产实践。
- 全栈开发：14 节，从 Web、HTTP、HTML、CSS、JavaScript 与 TypeScript 开始，深入 React、接口、数据库、GitHub 登录、安全、测试与部署。
- 产品实战：6 节，从用户任务与假设验证到工作流、界面和上线观察。
- 四阶段课程目录、继续学习入口、折叠课程导航、学习目标、案例与实践检查。
- 每条路径新增免登录综合自测，提供得分、解释、复习链接和重新作答。
- 保留 GitHub 登录、云端进度、正式结课考试和账户记录。
- 修复课程切换后题目选择与实践确认状态残留的问题，增加代码复制失败提示。
- 改善学习首页层次，复用现有 React Bits 文字动效并尊重减少动效设置。

## 兼容性与功能边界

- 原有课程链接与完成记录保留。正式考试要求完成扩展后的完整路径；既有考试记录不会改写。
- 正式考试保持每路径 6 题、至少答对 5 题通过；服务端评分和答案保护保留，无数据库迁移。
- 综合自测仅供开放复习，不上传成绩、不生成正式结课记录。实践任务为学习者自查，不提供自动代码评分。
- GitHub OAuth、跨设备进度及正式考试需要有效的 Supabase 配置；未配置时仍可浏览课程与完成本地自测。
- 本次发布不向 GitHub 提交 public/audio 文件。Cloudflare 部署仍按项目既有本地资源配置执行。
