# V2.1.0 — Analytics 与 Field Agent 更新

发布日期：2026-10-09。正式站点：<https://nextfield.top>。

## 更新内容

- Analytics 新增热门国家 / 地区榜，按 Cloudflare `visits` 汇总前十名；365 天筛选展示最近 30 天的地区汇总。
- Field Agent 额度调整为每 IP 每日 15 次、全站每日 300 次；本地开发与 Cloudflare Durable Object 限流使用相同上限。
- 调整全息信号矩阵在欢迎页和对话中的位置与背景，避免矩阵和欢迎内容相互遮挡；对话开始后矩阵移至上方并持续可见。
- 修正本地开发环境通过 `localhost` / `127.0.0.1` 访问时的请求来源校验。
- 补入 MCP 协议介绍的中英文文章。

## 部署与线上核对

- Cloudflare Worker：`nextfield-personal-site`。

## 构建说明

本地 Cloudflare 构建依赖 `.env.local` 与 `public/audio/` 资源。部署时保留 Worker 的 `DEEPSEEK_API_KEY` Secret、`FIELD_AGENT_LIMITER` Durable Object 绑定及 `field-agent-v1` SQLite 迁移。上述密钥不属于仓库或 Release 资产。
