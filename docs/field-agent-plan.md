# Field Agent — V2.0.0

更新日期：2026-10-09（UTC+8）。V2.0.0 已部署到 `https://nextfield.top`，正式 Field Agent 已启用。

## 功能与交互

- 免登录的站内探索助手，仅回答 NEXTFIELD 公开内容：项目、文章、建站纪事、制作说明、随笔、网站概览和作者介绍。
- 桌面使用 32rem 右侧面板，手机全屏；输入区固定，对话区单独滚动。顶栏、左下角常驻按钮和 Command Field 均保留入口。
- 开场采用 7×7 全息信号矩阵，颜色区分项目、文章、建站纪事、制作说明和随笔，每类两条真实内容。
- 待机光柱静止；鼠标指向的光柱及紧邻柱体抬升，选中顶面变亮，增加发光描边与局部光晕，移开后平滑恢复。其他光柱不跟随指针倾转或起伏。
- 点击光柱展开标题、简介与问题种子，提供“打开原文”“问问 Field Agent”“换一条”和关闭卡片；同主题内容可以轮换。
- “问问 Field Agent”只填入输入框，由访客确认发送。发现和切换卡片不调用模型、不扣额度；额度用完仍可阅读卡片和原文。
- 手机可点光柱或主题按钮，键盘可用方向键和 Enter；关闭卡片后焦点返回矩阵。
- 生成回答时显示缩小的波动矩阵。Canvas 每秒最多 30 帧，页面隐藏或面板卸载时停止并清理资源；关闭动效时保留静态布局和内容入口。

## 回答、资料与数据

模型通过服务端 DeepSeek API 接入。浏览器只请求本站接口，密钥不进入客户端。

- 使用真实流式输出，服务端解析模型 SSE 文字增量，以 NDJSON 发送额度、文字、完成与错误事件。
- 前端逐段呈现临时回答；完成后校验引用并写入历史。连接中断、回答截断或校验失败时移除临时回答，保留问题供重试。
- 正文隐藏引用编号，来源卡片只显示可点击标题；地址取自真实检索结果。编号检查约束来源范围，不等于自动证明每一句事实。
- 网站和作者介绍使用明确的资料入口；一般检索采用关键词与中文双字片段评分，仅明确追问继承上一轮关键词。
- 最近三轮对话用于理解追问；它们不替代本站资料。介绍类问题在资料充分时展开约 300–600 字，详细问题最多约 900 字；简单事实保持简洁，资料不足时明确说明。
- 问题、近期对话和相关站内资料会发送至 DeepSeek。对话保存在当前页面会话中，关闭面板或站内导航后保留，刷新后清空，未写入本站数据库或浏览器持久存储。

知识索引来自真实页面、公开数据及 Git 跟踪的非草稿、非示例文章。本次十三篇双语新文章通过 `content/field-agent-posts.json` 明确收录，其他本地文件不自动加入助手语料。课程暂只提供入口说明。

生成脚本：`scripts/build-field-agent-index.mjs`。开发、类型检查和构建前自动生成：

| 产物 | 使用方 | 内容 |
| --- | --- | --- |
| `lib/generated/field-agent-content.json` | 服务端检索 | 完整公开问答资料 |
| `lib/generated/field-agent-signals.json` | 客户端内容发现 | 十条轻量双语标题、简介、地址与问题种子 |

两份生成文件均被 Git 忽略。内容信号缺失来源时构建会报错。

## 匿名额度

- 每 IP 每日 15 次，全站每日 300 次，相邻请求至少间隔 5 秒。
- 北京时间（UTC+8）00:00 重置；失败请求也计入额度，共用网络可能共用额度。
- 生产使用单个 Cloudflare Durable Object 的持久化事务共享计数。
- 存储使用经 HMAC 处理的访客标识，不保存原始 IP。
- 本地 Next.js 开发仅使用进程内计数；生产缺少 `FIELD_AGENT_LIMITER` 绑定时拒绝提问。
- 当前限流实现面向 Cloudflare Workers。迁移到其他宿主时，需提供等效共享限流实现，不能直接使用开发计数器。

## 本地预览

在被忽略的 `.env.local` 中配置 `DEEPSEEK_API_KEY` 和 `DEEPSEEK_MODEL`。模型名按实际账户配置；当前示例为 `deepseek-flash`。本地进程启用开关：

```powershell
$env:FIELD_AGENT_ENABLED = 'true'
npm run dev -- --port 3334 --hostname 127.0.0.1
```

打开 `http://localhost:3334/`，点击 Field Agent。进程开关不会修改 `.env.local` 的默认值。

Workers 本地预览使用 `.dev.vars`，模板见 `.dev.vars.example`。配置本地密钥并按需启用助手后运行 `npm run preview`；它会先完成 Cloudflare 构建。
