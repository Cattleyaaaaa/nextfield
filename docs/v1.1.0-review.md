# V1.1.0 学习区重构 · 审核通过

用户已批准本次学习区重构。包版本与锁文件更新为 1.1.0；发布内容见 [V1.1.0 发布说明](releases/V1.1.0.md)。本文件保留课程审核入口、验收标准与功能边界。

## 审核入口

运行 `npm run dev -- -p 3333` 后访问：

- `/learn`：学习首页、路径选择和清晰的 GitHub 登录入口。
- `/learn/agent`：12 节 Agent 课程，从认识 Agent、LLM 到生产实践。
- `/learn/fullstack`：14 节全栈课程，从 Web、HTML、CSS、JavaScript 到交付。
- `/learn/product`：6 节产品课程，从用户任务到验证与观察。
- `/learn/review/agent`、`/learn/review/fullstack`、`/learn/review/product`：免登录综合自测，提交后显示得分、解释和复习章节链接。
- `/learn/exam`：正式考试入口，保留 GitHub 登录、服务端评分与账户记录。

## 体验检查

1. 进入两条主路径，确认由入门到深入的顺序与四阶段目录。
2. 打开第一课，查看学习目标、概念、案例、代码、动手任务和检查点。
3. 答对题目但尚未确认实践时，页面应引导回到任务；确认自查后才允许保存本课。
4. 切换到下一课，题目选择与任务确认必须重置；已完成的旧课程链接和进度仍保留。
5. 完成综合自测，确认解释可见、可重新作答，不会冒充正式考试成绩。
6. 切换中文/英文，检查目录、课程、题目与反馈；检查窄屏目录折叠和长文本排版。
7. GitHub 登录入口始终保留；真实 OAuth 需要有效 Supabase 与 GitHub 配置。

## 发布前边界

- 未配置 Supabase 时，可以浏览课程、做检查点与综合自测；真实登录、云端进度及正式考试不能完成。不能把本地模拟测试当作真实 OAuth 验收。
- 原有正式考试仍为每路径 6 题、5 题通过，不修改数据库结构；新增综合自测与正式考试分离。
- 扩展后需要完成该路径全部新旧课程才可参加正式考试，旧完成记录不删除。既有考试记录不改写。
- 参考学习时间是包含阅读与实践的估计，不是强制计时。
- 课程代码注明概念骨架；含外部函数的片段不是可以直接运行的完整项目。
- 学习页面采用现有 React Bits BlurText；尊重项目已有的减少动效设置。
- README 旧截图为此前版本，不宣称展示此次改版；正式发布前可更新学习页截图。

## 发布流程

更新 package.json 与 package-lock.json 至 1.1.0，完成构建与回归检查，提交到 GitHub，创建 V1.1.0 Release，然后重新构建并部署本地版本至 Cloudflare，最后检查 nextfield.top 的课程与登录入口。
