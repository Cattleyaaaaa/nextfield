# V4.1.0 — Field Radio 与导航细节

发布日期：2026-10-12。正式站点：<https://nextfield.top>。

## 更新内容

- 调整 Field Radio 纯净模式的整体布局，隐藏普通站点顶栏，让沉浸式聆听场景拥有完整空间。
- 重做目录入口与目录内容布局；曲目选择后展示当前封面，曲目列表支持鼠标滚动浏览。
- 重新排布悬浮歌词与播放控制，使两者宽度一致，并改善歌词阅读层级。
- 为顶栏的关于我、项目、写作和电台加入统一的组合线性图标，并保留轻量悬停反馈。
- 写作目录卡片显示文章标签，英文界面读取对应的英文标签。
