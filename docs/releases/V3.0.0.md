# V3.0.0 — 场域手记

发布日期：2026-10-11。正式站点：<https://nextfield.top>。

## 更新内容

- 将“写作”和“随笔”合并为《场域手记》，以封面、篇章目录和长文阅读组成完整阅读路径。
- 重构封面和目录开合过渡，使封面从自身尺寸展开到目录画布；文章正文默认连续下滑，可切换翻页，并支持目录抽屉、搜索和中英双语。
- 首次访问跟随浏览器语言选择中文或英文；其他语言偏好默认英文。手动切换后记住访客选择。
- 新增 7 篇中英双语文章与 3 篇随笔，并更新 Field Agent 站内检索索引。
- Field Radio 新增 9 首歌曲，曲目总数由 35 增至 44；新增发行封面和同名歌词。
- Cloudflare 构建前自动生成 Field Agent 内容索引，确保新内容进入线上版本。
