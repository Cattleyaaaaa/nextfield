这是一篇**格式示例**，用来演示这个博客的写作约定。看完把它删掉，换成你自己的文章即可。

## 文件放在哪、网址长什么样

文章是一个 `.mdx` 文件，放在 `content/posts/` 下。**文件名就是网址里的 slug**：

- `content/posts/rag-recall-notes.mdx` → `/blog/rag-recall-notes`

新增文章**不需要改任何代码**——构建时会自动扫描这个目录，列表页、阅读时长、站点地图都会跟着更新。

## frontmatter 字段

文件开头两行 `---` 之间是元数据：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `title` | 是 | 文章标题，列表页与详情页都用它 |
| `date` | 是 | `YYYY-MM-DD`，列表页会显示成 `2026 · 09` |
| `category` | 是 | 分类，决定列表页的筛选项（如 `教程`、`日常`、`项目`） |
| `tags` | 否 | 标签数组，写成 `["RAG", "检索"]` |
| `summary` | 否 | 一句话摘要，只有列表页会用到 |
| `sample` | 否 | 写成 `true` 会打上示例横幅，并阻止搜索引擎收录 |

阅读时长**不用手写**，构建期按正文的中文字数和西文词数自动估算。

## 支持的正文语法

### 二级与三级标题

正文里的 `##` 和 `###` 会自动渲染成衬线标题，和站点的排版语言一致。

### 列表

无序列表：

- 支持嵌套，但建议不超过两层
- 列表项里可以放 `行内代码`
- 也可以放[链接](https://example.com)

有序列表适合写步骤：

1. 把 `.mdx` 丢进 `content/posts/`
2. 填好 frontmatter
3. 重新构建站点

### 代码块

带语言标注的代码块会按等宽字体排版：

```ts
export function getAllPosts(): PostMeta[] {
  return getPostSlugs()
    .map((slug) => readPost(slug))
    .sort((a, b) => (a.date < b.date ? 1 : -1));
}
```

命令行的写法：

```bash
npm run build
```

### 引用

> 引用块适合放一段结论，或者从别处摘来的原文。
> 它不会加引号，只是用左边一条竖线做区分。

文字强调支持**加粗**和*斜体*。这个博客只用两档字重，所以加粗在视觉上比常规博客轻一些。

## 一个提醒

`title`、`summary` 这类文本里如果需要出现花括号或尖括号，请用反引号包起来，否则会被当成代码表达式解析。
