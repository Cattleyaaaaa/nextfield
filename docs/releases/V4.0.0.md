# V4.0.0 — Field Radio 音乐厅

发布日期：2026-10-12。正式站点：<https://nextfield.top>。

## 更新内容

- 重做 Field Radio 主界面：歌单、当前歌曲与封面、歌词采用并列布局。歌曲列表展示封面，并提供搜索和筛选。
- 页面内增加音量和播放方式控制，重做迷你播放器；在电台主界面与纯净模式之间切换时保持播放状态。
- 纯净模式使用跟随网站日间／夜间主题的沉浸场景。封面代表色围绕球体呈现呼吸光效，歌词当前句保持居中，并可从场景菜单访问播放控制、音量和播放方式。
- 音乐响应地面由立体方格组成，各方格按音频信号呈现不同高度变化。纯净模式下雨滴落在方格地面并向外触发方格涟漪；降低雨滴频率，减轻视觉噪声。
- 改善暂停、切歌和两种模式切换时的过渡，避免画面短暂黑屏。
