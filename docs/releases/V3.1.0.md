# V3.1.0 — 留言互动与关于页双语修正

发布日期：2026-10-12。正式站点：<https://nextfield.top>。

## 更新内容

- 留言可按登录账号点赞；访客可在自己或他人的留言下发表评论，并删除自己发布的留言与评论。
- 管理员身份由已验证的 GitHub OAuth 账号 ID 判断，可以删除全部留言与评论。匿名发布只隐藏公开署名，不改变权限。
- 关于页的分屏导航、简介、Agent 与全栈技术栈、近况及写作列表随中英文切换；英文写作列表使用英文标题、标签和阅读时长。
- 补齐 `guestbook_message_likes` 和 `guestbook_replies` 的 Supabase 迁移，按文件名顺序应用。迁移尚未应用时，留言列表仍可读取，评论入口会关闭。

## 部署说明

- Cloudflare Worker：`nextfield-personal-site`，正式域名：<https://nextfield.top>。
- Cloudflare Worker 版本 ID：`1ede1e71-3ba1-4d28-9ad5-0a138348f213`。

- GitHub 标签与 Release：`v3.1.0`。
- 本地 `.env.local`、Cloudflare 凭据、音频、构建产物与缓存均不进入 Git。
