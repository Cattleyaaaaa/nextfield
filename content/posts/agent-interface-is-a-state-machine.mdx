很多 Agent 产品从聊天框开始设计，但用户真正感受到的并不是聊天框，而是任务在不同状态之间如何流动。

## 结果之前发生了什么

一次 Agent 任务可能经历理解意图、规划步骤、调用工具、等待外部结果、请求用户确认和生成最终答案。只展示一个不断旋转的加载图标，会隐藏这些对用户判断非常重要的信息。

界面至少应该回答三个问题：现在正在做什么、是否需要我介入、失败后可以从哪里继续。

## 把控制权还给用户

暂停、取消、重试和修改输入不应该是异常路径。它们是长任务体验的一部分，也决定用户是否敢把更复杂的事情交给系统。

> Agent 的自然感，不来自拟人的措辞，而来自清晰、可预测并且可恢复的行为。
