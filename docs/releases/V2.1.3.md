# V2.1.3 — Field Agent 与 Field Radio 更新

发布日期：2026-10-11。正式站点：<https://nextfield.top>。

## 更新内容

- Field Agent 支持普通聊天，并按访客当前问题的语言回答；简单问候由服务端直接回复。
- 优化本站资料检索和页面导航回答，让助手更容易找到对应栏目与相关内容。
- Field Radio 播放器与电台主视觉共用 24 根频谱柱、频段映射和柱高轮廓；音符跟随实时音频分析。
- 更新 README、知识索引构建脚本和 Field Agent 使用说明。
